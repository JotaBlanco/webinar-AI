# S1 — bare model

Starting point. No tools, no system prompt, no project context, no skills. Pure model.

## Run

Vanilla chat session. Either:

- Open Claude.ai in a browser, paste the question of the day verbatim.
- Or one-shot SDK call (Claude Agent SDK or anthropic Python SDK), no system prompt, the question as the only user message.

## Expected failure modes

Per the proposal: at least two of these three — hallucinated project-specific parameter, wrong sign convention or units, generic textbook recipe ending. If you don't see at least two on the first try, the question needs sharpening (see your task's pre-recording calibration notes).

## What to save

The model's answer verbatim — copy/paste into slide 1 of the closing four-answer comparison. Do not edit. Do not paraphrase. The closing slide compares *exactly* what each scaffold produced.
