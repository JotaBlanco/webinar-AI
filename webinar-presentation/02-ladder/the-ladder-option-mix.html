The AI-Assisted Engineering Ladder — A/B Mix

Framing: what each rung adds, and what gap it closes. Four design treatments of the same slide.

Version 1 · Comparison table

What each rung adds — and the gap it closes.

Climbing isn't about a smarter model. It's about closing a specific gap between raw AI and a productive teammate.

Rung What's still missing What this rung adds
L0Chatbot Your world. Generic knowledge, no tools, no context. Conversation.
Answers questions in a vacuum — copy-paste is the integration.
L1Agentic AI Knowledge of how you work. Hands.
Reads your files, runs commands, opens PRs. Acts inside your environment.
L2+ Skills Knowledge of what you know. Muscle memory.
Reusable team procedures — the agent acts like someone who's done this before.
L3+ Knowledge Base A defined role in the org. Institutional memory.
Domain facts, past decisions, customer context — like a veteran teammate.
L4AI Harness — The workplace itself.
Governance, scheduling, sub-agents, audit. AI as infrastructure, not a tool.

Version 4 · Layers, not levels

Every rung is a new layer on top of the model.

The model never changes. What you stack around it does — and each layer unlocks new value.

System capability — stacked layers
L0 · Base modelConversation
L1 · + Tools & loop+ Hands
L2 · + Skills+ Muscle memory
L3 · + Knowledge base+ Institutional memory
L4 · + Harness+ Operating model
What each layer adds — and the gap it closes
L0 — Base model.
Gap: your world. Generic knowledge, no tools, no context.
L1 — Hands.
Gap closed: action. Still doesn't know how you work.
L2 — Muscle memory.
Gap closed: how. Still doesn't know what you know.
L3 — Institutional memory.
Gap closed: what. Still has no role in the org.
L4 — Operating model.
Gap closed: workplace. AI is now infrastructure, not a tool.
Same model from L0 to L4. The product is everything you stack around it.
